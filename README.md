# awesome-wasmcloud
wasmCloud community maintained repo for awesome components, host plugins, Workload examples, and tools

## Workload Examples
- [wasi-ai-app](https://github.com/bharattech/wasi-ai-app) — Local AI meeting-notes pipeline built from three Rust components: a transcriber (oxiwhisper + `ggml-tiny`), a summarizer (Candle + Qwen3-0.6B), and a web UI. Runs inference entirely on-device and ships a Kubernetes deployment guide.
